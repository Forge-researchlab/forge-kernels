# Examples

Runnable examples for forge-kernels. All require a CUDA GPU.

| Notebook | What it shows |
| --- | --- |
| [`quickstart_qwen.ipynb`](quickstart_qwen.ipynb) | Load Qwen2.5-0.5B, apply `forge.patch`, and measure the speedup and peak-memory delta over eager PyTorch |

Install dependencies from the repo root with `uv sync --dev` (or
`pip install -e . transformers`), then open the notebook.
